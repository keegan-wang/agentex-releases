# AgentTeX downloads

This repository contains public macOS downloads and signed update files for AgentTeX. The application source is maintained separately in a private repository.

[Download the latest release](https://github.com/keegan-wang/agentex-releases/releases/latest)

The universal DMG runs on Apple Silicon and Intel Macs with macOS 12 or later. Open the DMG and drag AgentTeX into Applications.

Starting with version 0.2.1, AgentTeX checks for new releases automatically. Use **Updates** to download a verified update and install it when you are ready to restart. Older versions need the new DMG once to enable this feature.

The `.app.tar.gz`, `.sig`, and `latest.json` assets are for the in-app updater; use the `.dmg` for a first installation. No GitHub account is needed to download releases.
